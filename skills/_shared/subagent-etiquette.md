# Subagent etiquette

<!-- distinctive: A subagent owns one stage and reports through state, never through prose markers. -->

A subagent owns one stage and reports through state, never through prose markers.

- Read the skill file named in your dispatch and request the brief first; the brief is the only source of unit context you trust.
- Do the stage's work, record evidence with the `evidence` tool, and finish with `unit report` carrying outcome, summary, questions and artifacts.
- Never advance the unit yourself when dispatched by a conductor; the conductor routes.
- Never post to a tracker, code host or chat without the human's explicit approval in this session. Draft to `drafts/` instead.
- If a role you need is `unwired`, skip the step, and say so in your report.
- Do not start work on another unit, another stage, or the next cycle.
